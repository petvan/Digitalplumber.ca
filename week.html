5 developments that mattered

Picked by the AI editor

  1. Security·Industry news

    State actors exploit maximum-severity Cisco SD-WAN bypass to steal keys

    State-linked APT group UAT-11473 exploited CVE-2026-20127, a maximum-severity authentication bypass in Cisco Catalyst SD-WAN Controller/Manager, to gain admin access and install KeyDrift—a malware framework that steals AES-256 encryption keys from the control plane.

    Why it matters A CVSS 10 auth bypass in Catalyst SD-WAN Manager with key-stealing malware puts the WAN control plane directly at risk.

    CyberSecurityNews · Oct 31, 2026 edition

  2. Automation·Industry news

    Capobianco releases NetClaw open source MCP network assistant

    John Capobianco released NetClaw, an open-source automation assistant for network engineers built on MCP (Model Context Protocol) with production-safe security architecture.

    Why it matters A free, MCP-based network assistant with safety guardrails gives NetDevOps teams a practical way to trial agentic troubleshooting.

    Packet Pushers (Heavy Networking podcast) · Oct 31, 2026 edition

  3. AIOps·Industry news

    ThousandEyes adds BGP monitoring for internal enterprise routes

    Cisco ThousandEyes introduced Enterprise Routing Assurance, a BGP monitoring feature enabling visibility into internal enterprise network routes that public BGP monitors cannot observe, using dedicated agent-based telemetry collection.

    Why it matters Enterprise Routing Assurance closes the internal-BGP blind spot public route monitors have never covered.

    SDxCentral · Oct 30, 2026 edition

  4. Startups·Industry news

    Serval raises $150M to push automation agents beyond IT

    Enterprise service management startup Serval raised $150 million at a $3 billion valuation to expand its automation agents beyond IT operations, including new Catalyst agent for scanning support tickets and auto-generating workflows.

    Why it matters A $150M round at $3B valuation signals investor conviction that automation agents will absorb IT operations workflows.

    SiliconANGLE · Nov 2, 2026 edition

  5. Research·Primary source

    OpenTelemetry eBPF instrumentation reaches version 1.0

    OpenTelemetry eBPF Instrumentation (OBI) v1.0.0 brings zero-code observability to running Linux applications using eBPF and runtime-specific instrumentation to capture metrics and traces across services, languages, and frameworks without code modification.

    Why it matters OBI v1.0 makes eBPF zero-code tracing production-ready, changing how SREs instrument services without touching code.

    OpenTelemetry Blog · Oct 30, 2026 edition
