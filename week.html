    NetBox MCP server goes GA for AI-driven infrastructure changes

    Arista CloudVision, AWS VPC IPAM, and Cisco Nexus Dashboard integrations become generally available in October; NetBox Agents gains pre-built agents for change request review, lifecycle compliance, and data import in public preview; the NetBox Platform MCP Server (now GA) enables AI agents to query and change infrastructure in plain language.

  2. AIOps·Vendor release

    Selector Foundry lets NetOps teams build and version AI agents

    Selector introduced Selector Foundry, a development and runtime environment that lets network operations teams build, test, version and govern their own AI agents inside the Selector platform, where operators author agents where their telemetry is correlated, store them in Git, and validate against historical incidents before production.

    Why it matters Git-versioned, testable NetOps agents validated against historical incidents is the first credible answer to agent governance in network operations.

    Selector · Oct 15, 2026 edition

  3. DC networking·Industry news

    Ultra Ethernet 1.1 adds programmable congestion control

    UEC released Version 1.1 on October 13 to boost scale-up networking and improve congestion control as AI workloads surge through high-end networks.

    Why it matters UEC 1.1's programmable congestion management directly shapes how AI fabrics are built and tuned at million-GPU scale.

    SDxCentral · Oct 15, 2026 edition

  4. Security·Industry news

    Ivanti Connect Secure zero-day chain grants unauthenticated root

    CISA urged immediate patching of CVE-2026-104935, an Ivanti Connect Secure authentication bypass exploited in zero-day attacks since October 1st that lets remote threat actors execute arbitrary commands without credentials.

    Why it matters Unauthenticated root on Ivanti Connect Secure, exploited since October 1, demands immediate patching of edge VPN appliances.

    BleepingComputer · Oct 14, 2026 edition

  5. Startups·Industry news

    Pluto Security leaves stealth with $42m to govern AI tools

    Pluto Security emerged from stealth with $42M in total funding ($8.5M seed led by TLV Partners, $34M Series A led by Jump Capital) to secure AI applications and agentic workflows at the endpoint level.

    Why it matters Stealth exit with $42M for endpoint-level agent governance signals where AI security spending and agentic ops controls are heading.
