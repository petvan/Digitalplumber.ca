5 developments that mattered

Picked by the AI editor

  1. Security·Primary source

    Arista VeloCloud Orchestrator hit by third exploited zero-day

    Arista disclosed an actively exploited CVSS 9.9 SQL injection zero-day (CVE-2026-114625) in VeloCloud Orchestrator, the central management plane for SD-WAN networks. Any authenticated user—even read-only accounts—can escalate to superuser operator privileges.

    Why it matters VeloCloud Orchestrator is the SD-WAN control plane; a third actively exploited zero-day in 87 days means operators must assume compromise and audit tenant accounts.

    Arista Security Advisory 0199, SecurityWeek, Aviatrix Threat Research · Oct 27, 2026 edition

  2. Startups·Primary source

    Nvidia launches Minerva AIOps platform for AI factories

    Nvidia announced Minerva, an AIOps platform for AI factories that consolidates GPU, network, storage, job scheduler, and workload telemetry into a unified view and applies purpose-built AI models to detect degradation and predict failures before they impact productivity.

    Why it matters Nvidia Minerva pushes AIOps into GPU fabric telemetry, directly competing with incumbent observability stacks for AI-factory operations teams.

    Nvidia / The Next Web · Oct 23, 2026 edition

  3. Startups·Vendor release

    Ultra Security leaves stealth with $10M for agent policing

    Ultra Security, a Birmingham, Michigan startup founded in 2025, emerged from stealth with $10M seed funding for an agentic security platform that sits between AI agents and MCP servers to enforce policy on every tool call, data read, and prompt request in real time.

    Why it matters Ultra Security's stealth exit targets the MCP tool-call layer, exactly where NetDevOps teams now need policy enforcement for agents.

    Business Wire · Oct 23, 2026 edition

  4. Agentic AI·Vendor release

    Itential opens AI skills and MCP server to coding agents

    Itential unveiled Itential AI Skills, an open-source portfolio enabling teams to build, operate, and administer the Itential Platform through leading AI coding environments like Claude Code, Codex CLI, GitHub Copilot, and Cursor.

    Why it matters Itential's open-source AI Skills and MCP server let engineers drive network automation platforms from Claude Code, Cursor and Copilot.

    PRNewswire / Itential · Oct 28, 2026 edition

  5. Telco·Industry news

    Deutsche Telekom extends agentic remediation across whole network

    Deutsche Telekom's RAN Guardian live system uses three agents to identify events, assess network impact and autonomously implement remediation.

    Why it matters Deutsche Telekom's MINDR shows multi-agent remediation running live across domains inside guardrails, a concrete template for autonomous NetOps.

    RCR Wireless · Oct 23, 2026 edition
