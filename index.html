MCP 2026-07-28 Release Candidate: Stateless Core, Tasks Extension, Auth Hardening — Official AAIF Post

Remote MCP servers that previously required sticky sessions or distributed session stores can now run behind plain round-robin load balancers; new Mcp-Method and Mcp-Name headers let gateways and rate-limiters route without body inspection.
