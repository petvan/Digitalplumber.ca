Black Hat USA 2026: GPUBreach Research Shows Rowhammer Attacks Can Escalate From Nvidia GDDR6 Memory

Black Hat USA 2026 opens August 1 with GPUBreach, the first research showing Rowhammer attacks can escalate from Nvidia GDDR6 GPU memory to a host root shell bypassing IOMMU. This is the first publicly disclosed privilege escalation vulnerability in GPU memory that reaches the host system, with significant implications for hyperscale AI infrastructure security.

NvidiaGPU SecurityRowhammerBlack HatInfrastructure Security

Security researchers will debut GPUBreach at Black Hat USA 2026 (August 1–6), revealing the first known Rowhammer attack capable of escalating from Nvidia GPU memory directly to host root access, bypassing the IOMMU (Input/Output Memory Management Unit). This represents a critical attack surface in large-scale AI deployments where thousands of GPUs share infrastructure. For AIOps and SRE teams managing multi-tenant GPU clusters—common in neocloud and hyperscaler environments—this finding demands immediate attention to memory isolation policies, IOMMU enforcement, and GPU memory access controls. The vulnerability affects Nvidia's GDDR6 GPU memory under typical data center operating conditions. Infrastructure architects must review GPU workload isolation and consider whether shared GPU clusters require additional hardware or software mitigations. This will likely trigger new supply-chain and procurement conversations around GPU security profiles in production AI deployments.

Noma Security Jul 30, 2026 Security

RufRoot: Critical MCP Bridge Vulnerability Exposes 233 Unauthenticated Tools in Ruflo Agent Platform (CVE-2026-59726)

Noma Labs discovered a critical CVSS 10.0 vulnerability in Ruflo, an open-source AI agent orchestration platform with over 67,000 GitHub stars. The platform's MCP Bridge exposes 233 tools over HTTP with zero authentication, allowing a single unauthenticated HTTP POST request to port 3001 to run arbitrary shell commands. This directly impacts DevOps and MLOps teams using AI coding agents for infrastructure automation.

The vulnerability (CVE-2026-59726, CVSS 10.0) impacts all Ruflo versions before 3.16.3. Ruflo's MCP Bridge, an Express.js server, exposes 233 internal tools over HTTP without authentication, including capabilities for shell execution, database access, agent orchestration, and persistent memory management. As organizations deploy agentic AI for automation—Ruflo has approximately 10 million downloads and 1 million active users—platforms like this are quickly entering corporate environments as Shadow AI. The implications are severe for any DevOps pipeline using Ruflo for AI-assisted infrastructure tasks: attackers can inject malicious code, steal LLM API keys, poison agent memory, and hijack automated workflows. In default docker-compose deployments where the bridge is bound to all interfaces, an unauthenticated attacker could invoke terminal_execute to run commands inside the container and access stored provider API keys. Practitioners should immediately upgrade to version 3.16.3 and audit CI/CD logs for unauthorized agent activity.
