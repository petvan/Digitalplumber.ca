Cloudflare Blog Aug 6, 2026 Product Launch

Cloudflare Kitesurf: Stateless Browser for AI Agents on Workers Infrastructure

Kitesurf is Cloudflare's stateless, highly scalable, cost-effective web browser running entirely on Workers, designed specifically for the Agentic Cloud. The architecture trades traditional browser resource overhead for Cloudflare's distributed compute model.

CloudflareAgentsWorkersBrowser Automation

Kitesurf is designed to give agents tools optimized for AI model interactions—a stateless browser running entirely on Cloudflare Workers that trades traditional browser state management for horizontal scalability. Unlike Puppeteer or Playwright (which maintain long-lived processes and DOM state), Kitesurf runs request-scoped and sandboxed: each agent request spawns an isolated browser instance on Workers, executes navigation/interaction, and discards state. This eliminates the cost and complexity of managing persistent browser processes at scale—critical for infrastructure where agents need to inspect thousands of dashboards, APIs, or admin panels in parallel. For SREs and NetOps teams, Kitesurf removes the infrastructure tax of browser-based agent orchestration: no connection pooling tuning, no memory leaks, no session affinity headaches. The stateless design also enforces security boundaries naturally—each agent invocation is fully isolated. Performance implications: agent control-loop latency is bounded by Workers cold-start + navigation time, not by browser process scheduling.

For network operators managing hybrid cryptographic postures (not all devices can support post-quantum algorithms yet), this hybrid scheme buys time. Carahsoft's distribution handles FedRAMP certification and procurement compliance—infrastructure teams don't have to navigate approval separately.
