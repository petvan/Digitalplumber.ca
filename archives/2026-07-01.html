MCP Goes Stateless: The 2026-07-28 Release Candidate Explained

The MCP 2026-07-28 release candidate removes protocol-level sessions and the Mcp-Session-Id header, enabling stateless operation on commodity HTTP infrastructure. Six SEPs implement stateless routing via Mcp-Method and Mcp-Name headers, standardized caching with ttlMs/cacheScope, and OpenTelemetry trace propagation. Breaking changes include deprecated Roots, Sampling, and Logging; a 12-month deprecation window applies before removal.

OpenTelemetry Blog Jun 2026 Standards

OpenTelemetry Deprecates OpenCensus Compatibility Requirements in Specification

On June 12, 2026, the OpenTelemetry Specification project merged PR #5138, deprecating OpenCensus compatibility requirements in the specification. This change updates the specification to match where the ecosystem already is: OpenCensus has been archived since July 31, 2023, and the OpenTelemetry shims for OpenCensus have provided a stable migration bridge for more than three years. New SDKs and implementations no longer need to support OpenCensus compatibility; new work should target native OpenTelemetry APIs, SDKs, and OTLP-based workflows instead.
